# SMT902 suppression-without-reason

An inline suppression without a `-- reason`.

- **Category:** meta
- **Default severity:** error
- **Fixable:** no

## Why

Every exception to the architecture should explain itself, so the next person (or agent) knows whether it can be removed.

## Bad

```python
from app.infra import Db  # smelt: ignore[SMT101]
```

## Good

```python
from app.infra import Db  # smelt: ignore[SMT101] -- migration tracked in #123
```

## How to fix

Append ` -- <reason>` to the comment.

## Config

- `suppressions.require_reason`

Explain it in the terminal with `smelt explain SMT902`.

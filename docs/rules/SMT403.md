# SMT403 private-access

A test reads, writes or imports private names of first-party code.

- **Category:** tests
- **Default severity:** error

## Why

Private attributes are free to change. Tests that reach into them fail on harmless refactorings and verify wiring instead of behavior.

## Bad

```python
service._repository = FakeRepository()
```

## Good

```python
service = VoiceService(repository=FakeRepository())
```

## How to fix

Go through the public API, or make the dependency a constructor parameter.

## Config

- `tests.private_access`

Explain it in the terminal with `smelt explain SMT403`.

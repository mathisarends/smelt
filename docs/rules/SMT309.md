# SMT309 forbidden-module-docstring

A module docstring is forbidden by the package's explicit convention.

- **Category:** structure
- **Activation:** policy — A package contract forbids module docstrings.
- **Severity when active:** error

## Why

Some projects keep module descriptions in their architecture documentation. This opt-in convention checks the module's initial docstring, not function or class documentation or ordinary strings.

## Bad

```python
"""Redundant module introduction."""
VALUE = 1
```

## Good

```python
VALUE = 1

def calculate():
    """Explain the calculation contract."""
```

## How to fix

Remove or move the module introduction according to the package's policy. No documentation is deleted automatically.

## Config

- `structure.contracts`

Explain it in the terminal with `smelt explain SMT309`.

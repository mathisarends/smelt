# SMT301 unknown-layer

A feature contains a package that is not a declared layer.

- **Category:** structure
- **Default severity:** error

## Why

Packages outside the layer grid are invisible to every layer rule: code in voice/models/ can import anything and be imported by anything.

## Bad

```python
voice/
  domain/
  application/
  models/      # not a layer
```

## Good

```python
voice/
  domain/
    models.py
  application/
```

## How to fix

Move the modules into a layer, declare the package under architecture.layers, or add it to architecture.shared.

## Config

- `architecture.layers`

Explain it in the terminal with `smelt explain SMT301`.

# SMT301 unknown-layer

A feature contains a package or module outside the declared layers.

- **Category:** structure
- **Default severity:** error

## Why

Code outside the layer grid is invisible to every layer rule: voice/models/ or voice/helpers.py can import anything and be imported by anything. A feature's __init__.py is fine, and not every feature needs every layer.

## Bad

```python
voice/
  domain/
  application/
  models/      # not a layer
  helpers.py   # in no layer
```

## Good

```python
voice/
  domain/
    models.py
  application/
```

## How to fix

Move the code into a declared layer, or declare its package as a layer if the architecture has a distinct responsibility for it.

## Config

- `architecture.layers`

Explain it in the terminal with `smelt explain SMT301`.

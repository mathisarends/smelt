# SMT314 bundled-instance-assignment

An assignment writes multiple direct instance attributes under a separate-assignment convention.

- **Category:** structure
- **Activation:** policy — A package contract requires separate instance assignments.
- **Severity when active:** error

## Why

Separate field assignments make object initialization easy to scan and extend. This opt-in package convention reports tuple/list unpacking and chained assignments that write multiple direct attributes of a method's first positional parameter, regardless of its name. It leaves local unpacking and single-field assignments alone. Recognized static/class methods and nested helper bodies are excluded; nested classes are inspected with their own receiver. This is a readability policy, not a logic error.

## Bad

```python
class Inbox:
    def __init__(self, log, control):
        self.log, self.control = log, control
```

## Good

```python
class Inbox:
    def __init__(self, log, control):
        self.log = log
        self.control = control
```

## How to fix

Use one direct instance attribute write per statement. Preserve evaluation timing: unpack computed values into locals before assigning fields when appropriate. Parallel assignments, swaps, descriptors and unpacking failures can behave differently when split, so there is no automatic rewrite.

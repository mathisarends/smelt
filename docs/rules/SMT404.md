# SMT404 mocks-first-party

A test mocks a first-party class from a layer in mocks.forbid_first_party.

- **Category:** tests
- **Default severity:** warning

## Why

A mock of your own port accepts any call sequence. A small fake that implements the port behaves like the real thing and survives refactorings.

## Bad

```python
sessions = create_autospec(VoiceSessionRepository)
```

## Good

```python
class FakeSessions(VoiceSessionRepository):
    def __init__(self) -> None:
        self.saved: list[VoiceSession] = []
```

## How to fix

Write a fake implementing the port and assert on its state.

## Config

- `tests.mocks.forbid_first_party`

Explain it in the terminal with `smelt explain SMT404`.

# SMT304 crowded-package

A package has more modules than structure.crowded_threshold.

- **Category:** structure
- **Default severity:** hint
- **Fixable:** no

## Why

A flat package with many modules hides which of them belong together. This is advisory: grouping is a judgement call.

## Bad

```python
voice/application/
  start.py
  stop.py
  ... 13 modules
```

## Good

```python
voice/application/
  sessions/
  recordings/
```

## How to fix

Group related modules into subpackages, or raise the threshold.

## Config

- `structure.crowded_threshold`

Explain it in the terminal with `smelt explain SMT304`.

# SMT101 layer-boundary

A layer imports a layer outside its `may_depend_on` allowlist.

- **Category:** dependencies
- **Default severity:** error

## Why

Layers only stay replaceable and testable when dependencies point in one direction. An application service that imports infrastructure cannot be used without the database, HTTP client or framework behind it.

## Bad

```python
# voice/application/session.py
from gateway.features.voice.infra.sql import SqlVoiceSessionRepository
```

## Good

```python
# voice/application/session.py
from gateway.features.voice.application.ports import VoiceSessionRepository

# gateway/bootstrap.py wires SqlVoiceSessionRepository to the port
```

## How to fix

Depend on an abstraction (a port) owned by the importing layer or an allowed layer, and wire the concrete implementation in the composition root.

## Config

- `architecture.layers.<layer>.may_depend_on`
- `architecture.imports.transitive`
- `architecture.imports.type_checking`

Explain it in the terminal with `smelt explain SMT101`.

# SMT206 self-class-reference

A method constructs or returns its own class by name instead of cls(...)/type(self)(...) or Self.

- **Category:** code
- **Default severity:** off by default (warning when enabled)

## Why

Hard-coding the class name breaks subclasses: Money.add returns Money even when called on Euro. cls, type(self) and Self follow the actual type.

## Bad

```python
class Money:
    def add(self, other: "Money") -> "Money":
        return Money(self.cents + other.cents)
```

## Good

```python
class Money:
    def add(self, other: Self) -> Self:
        return type(self)(self.cents + other.cents)
```

## How to fix

Use cls(...) in classmethods, type(self)(...) in methods and Self in annotations.

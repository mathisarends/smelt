# SMT302 forbidden-package-name

A package or module name is listed in structure.forbidden_names.

- **Category:** structure
- **Default severity:** error
- **Fixable:** no

## Why

Names like utils or helpers describe nothing, so everything fits in them. They grow into grab bags that every layer imports.

## Bad

```python
voice/application/utils.py
```

## Good

```python
voice/application/durations.py
```

## How to fix

Name the module after what it does, or move each function next to its callers.

## Config

- `structure.forbidden_names`

Explain it in the terminal with `smelt explain SMT302`.

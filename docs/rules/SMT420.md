# SMT420 private-test-access

A test imports or reads a private production name through a known module or instance.

- **Category:** tests
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** error

## Why

Testing an observable public contract lets internal helpers change without rewriting tests. This opt-in convention checks imports, module-qualified accesses and direct instance reads/calls into analyzed production modules. Instance provenance comes from known production constructors (including analyzed facade re-exports), explicit annotations, and fixture returns/yields with an annotation or consistent known constructor/alias shape. Fixed tuple fixtures preserve known component types when unpacked. Unknown factories, conflicting outputs, reflection, local fakes and dunder names are excluded. Instance assignments are excluded so intentional immutability probes remain valid. A deliberate public re-export remains public. No general type inference or fixture execution is performed.

## Bad

```python
from app.service import _normalize
def test_normalize():
    assert _normalize('A') == 'a'
```

## Good

```python
from app.service import normalize
def test_normalize():
    assert normalize('A') == 'a'
```

## How to fix

Exercise the supported behavior that uses the helper. Keep a reasoned exception for a deliberate implementation/protocol test; do not expose internals solely to silence a warning.

## Config

- `rules`
- `tests.quality_exclude`

# SMT420 private-test-access

A test explicitly imports or accesses a private production name through a module.

- **Category:** tests
- **Activation:** policy — tests.forbid_private_imports is enabled.
- **Severity when active:** error

## Why

Testing an observable public contract lets internal helpers change without rewriting tests. This opt-in convention checks imports and module-qualified attribute accesses into analyzed production modules, including underscore-prefixed module segments. It excludes local test helpers, unrelated third-party internals and special dunder names. It does not infer instance types or inspect reflection/string lookups; a deliberate public re-export remains public.

## Bad

```python
from app.service import _normalize
def test_normalize():
    assert _normalize('A') == 'a'
```

## Good

```python
from app.service import normalize
def test_normalize():
    assert normalize('A') == 'a'
```

## How to fix

Exercise the public behavior that uses the helper, or deliberately expose a supported interface. Use a reasoned suppression for a focused implementation test you intend to keep.

## Config

- `tests.forbid_private_imports`
- `tests.quality_exclude`

Explain it in the terminal with `smelt explain SMT420`.

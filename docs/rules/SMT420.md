# SMT420 private-test-access

A test imports or reads a private production name through a known module or instance.

- **Category:** tests
- **Activation:** policy — tests.forbid_private_imports is enabled.
- **Severity when active:** error

## Why

Testing an observable public contract lets internal helpers change without rewriting tests. This opt-in convention checks imports, module-qualified accesses and direct instance reads/calls into analyzed production modules. Instance provenance comes from known production constructors, explicit annotations and annotated local/conftest fixture returns. Simple aliases are tracked; unknown factories, reflection, local fakes and dunder names are excluded. Instance assignments are excluded so intentional immutability probes remain valid. A deliberate public re-export remains public. No general type inference or fixture execution is performed.

## Bad

```python
from app.service import _normalize
def test_normalize():
    assert _normalize('A') == 'a'
```

## Good

```python
from app.service import normalize
def test_normalize():
    assert normalize('A') == 'a'
```

## How to fix

Exercise the public behavior that uses the helper, or deliberately expose a supported interface. Use a reasoned suppression for a focused implementation test you intend to keep.

## Config

- `tests.forbid_private_imports`
- `tests.quality_exclude`

Explain it in the terminal with `smelt explain SMT420`.

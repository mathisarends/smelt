# SMT903 stale-baseline

A baseline entry that no longer matches any violation.

- **Category:** meta
- **Default severity:** warning
- **Fixable:** no

## Why

Fixed violations should leave the baseline, otherwise they could silently come back.

## Bad

```python
{"code": "SMT101", "path": "app/application/old.py", ...}
```

## Good

```python
(entry removed after the violation was fixed)
```

## How to fix

Run `smelt baseline --prune`.

## Config

- `baseline`

Explain it in the terminal with `smelt explain SMT903`.

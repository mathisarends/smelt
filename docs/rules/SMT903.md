# SMT903 resolved-debt

A debt entry that no longer matches any violation.

- **Category:** meta
- **Default severity:** warning

## Why

Fixed violations should leave the debt file, otherwise they could silently come back.

## Bad

```python
{"code": "SMT101", "path": "app/application/old.py", ...}
```

## Good

```python
(entry removed after the violation was fixed)
```

## How to fix

Run `smelt debt --prune`.

## Config

- `debt`

Explain it in the terminal with `smelt explain SMT903`.

# SMT106 composition-root-leak

A module imports the composition root or a declared wiring module.

- **Category:** dependencies
- **Default severity:** error

## Why

Wiring belongs in one place. When features reach for the container or the bootstrap module, construction logic spreads and dependencies become hidden.

## Bad

```python
# voice/application/session.py
from gateway.main import container
```

## Good

```python
# voice/application/session.py
class StartSession:
    def __init__(self, sessions: VoiceSessionRepository) -> None: ...
```

## How to fix

Receive dependencies through constructor parameters and register them in the composition root.

## Config

- `architecture.composition_root`
- `architecture.wiring`

Explain it in the terminal with `smelt explain SMT106`.

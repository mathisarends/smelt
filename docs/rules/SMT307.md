# SMT307 missing-required-module

A package contract is missing a required module or public entry point.

- **Category:** structure
- **Default severity:** error

## Why

Explicit package contracts let contributors and agents follow the same structure. They apply only to matching packages and require no particular framework, feature layout or layer names. Excluded code does not fulfill a contract. This checks presence, not implementation quality.

## Bad

```yaml
structure:
  contracts:
    slices:
      match: app.slices.*
      required: [api]   # app.slices.orders.api is absent
```

## Good

```yaml
structure:
  contracts:
    slices:
      match: app.slices.*
      required: [api]   # every matching package has an api module or package
```

## How to fix

Implement the missing module in the matching package. If that package should follow a different structure, narrow or split the contract. Do not add empty implementation stubs solely to satisfy the check.

## Config

- `structure.contracts`

Explain it in the terminal with `smelt explain SMT307`.

# SMT407 test-bloat

A change adds far more test code than production code.

- **Category:** tests
- **Default severity:** hint

## Why

Test code is code to maintain. Hundreds of test lines for a small change usually mean copy-pasted setup or tests of implementation details.

## Bad

```python
+420 test lines for a 12-line change
```

## Good

```python
one focused, parametrized test per behavior
```

## How to fix

Parametrize similar cases, share setup in fixtures and drop redundant tests.

## Config

- `tests.bloat.ratio`
- `tests.bloat.min_test_loc`

Explain it in the terminal with `smelt explain SMT407`.

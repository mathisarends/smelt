# SMT406 interaction-assertion

A test asserts how a first-party collaborator was called.

- **Category:** tests
- **Default severity:** warning
- **Fixable:** no

## Why

call_count and assert_called_* pin the implementation: the test fails when the code reaches the same result differently. Assert on results, state or emitted events. Boundary mocks (HTTP clients, the clock) are exempt.

## Bad

```python
sessions.save.assert_called_once_with(session)
```

## Good

```python
assert sessions.saved == [session]
```

## How to fix

Assert on the returned value or on the state of a fake.

## Config

- `tests.interaction_assertions`

Explain it in the terminal with `smelt explain SMT406`.

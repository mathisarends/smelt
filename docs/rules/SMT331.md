# SMT331 yaml-file-extension

A YAML filename uses a different extension from the project's canonical spelling.

- **Category:** structure
- **Activation:** policy — structure.file_naming.yaml_extension selects a canonical YAML extension.
- **Severity when active:** error

## Why

Choose yaml or yml once in structure.file_naming.yaml_extension to keep configuration filenames consistent. The policy checks lowercase .yaml and .yml filenames below the directory containing smelt.yml, including the Smelt configuration itself, Compose files and hidden directories such as .github. Project exclusions and tool/cache directories are skipped. No YAML contents are parsed, and an omitted policy permits either spelling even with --select ALL.

## Bad

```yaml
# With yaml_extension: yaml
# settings.yml
```

## Good

```yaml
# With yaml_extension: yaml
# settings.yaml
```

## How to fix

Rename the file to the expected path and update references to its old name, including CI, scripts and extends entries. No file or reference is changed automatically. Use a reasoned project.exclude or ignore.paths entry for filenames required by another tool.

## Config

- `structure.file_naming.yaml_extension`
- `project.exclude`
- `ignore`

Explain it in the terminal with `smelt explain SMT331`.

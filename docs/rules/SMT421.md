# SMT421 forbidden-test-mock

A recognized mocking operation occurs in a test path that forbids mocks.

- **Category:** tests
- **Default severity:** error

## Why

Domain tests can exercise real domain objects and injected fakes. This opt-in path policy rejects recognized unittest.mock constructors/patching and standard pytest-mock fixture operations, including setup fixtures. It does not infer arbitrary test doubles or traverse fixture dependencies.

## Bad

```python
from unittest.mock import Mock
def test_rule():
    service = Mock()
```

## Good

```python
def test_rule():
    result = calculate_total([10, 20])
    assert result == 30
```

## How to fix

Use real domain objects or a small fake implementing the port. Keep boundary mocking in explicitly permitted test paths; use a reasoned suppression for an intentional exception.

## Config

- `tests.forbid_mocks_in`
- `tests.quality_exclude`

Explain it in the terminal with `smelt explain SMT421`.

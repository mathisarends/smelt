# SMT311 unnecessary-future-annotations

Review an annotations future import with no detected postponement need.

- **Category:** structure
- **Default severity:** hint

## Why

On targets before Python 3.14 or with an unknown minimum, when-needed mode retains imports for quoted and unresolved forward references, TYPE_CHECKING, runtime annotation inspection, decorated definitions and complex annotation expressions. Other cases get a conservative review hint, not proof of safe removal. Declared Python 3.14+ targets are handled by SMT310.

## Bad

```python
from __future__ import annotations

def count(value: int) -> int:
    return value
```

## Good

```python
def count(value: int) -> int:
    return value
```

## How to fix

Review whether postponement is part of the module's runtime contract, then remove unnecessary boilerplate and verify types and behavior. Keep the import if it serves a real purpose; annotate a justified exception if required.

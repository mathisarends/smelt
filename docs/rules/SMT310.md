# SMT310 forbidden-future-annotations

The annotations future import violates a package or Python-version policy.

- **Category:** structure
- **Default severity:** error

## Why

An explicit source convention can forbid this import. In when-needed mode, a declared Python 3.14+ minimum also makes it a violation because annotations are already deferred by default. The future import still changes runtime representation, so removal requires checking annotation consumers and never happens automatically.

## Bad

```python
from __future__ import annotations

VALUE = 1
```

## Good

```python
VALUE = 1
```

## How to fix

Follow the declared convention while preserving forward references and runtime behavior. When-needed mode gives review hints on earlier or unknown targets and rejects the import on declared Python 3.14+ targets. An explicit allow exception can retain a runtime compatibility contract. No automatic rewrite is performed.

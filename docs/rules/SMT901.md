# SMT901 unused-suppression

An inline `# smelt: ignore[...]` comment that suppresses nothing.

- **Category:** meta
- **Default severity:** warning
- **Fixable:** `smelt fix SMT901`

## Why

Stale suppressions hide future violations on the same line and make readers believe there is an exception where there is none.

## Bad

```python
import os  # smelt: ignore[SMT101] -- legacy
```

## Good

```python
import os
```

## How to fix

Remove the comment, or the unused codes from it. `smelt fix SMT901` does this.

## Config

- `suppressions.require_reason`

Explain it in the terminal with `smelt explain SMT901`.

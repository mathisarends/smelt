# SMT901 unused-suppression

An inline suppression is unused or names an unknown identifier.

- **Category:** meta
- **Activation:** default — Enabled by default.
- **Severity when active:** warning

## Why

Stale suppressions hide future violations on the same line and make readers believe there is an exception where there is none. Unknown identifiers, including rule names instead of SMT codes, are diagnosed even in narrowed checks when SMT901 is selected. Known inactive rules are not treated as unknown. Inline comments continue to accept stable SMT codes and prefixes; YAML and CLI also accept rule names.

## Bad

```python
import os  # smelt: ignore[SMT101] -- legacy
```

## Good

```python
import os
```

## How to fix

Remove the comment, or the unused codes from it.

## Config

- `suppressions.require_reason`

Explain it in the terminal with `smelt explain SMT901`.

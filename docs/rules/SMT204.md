# SMT204 misplaced-role

A class with a role lives in a layer outside roles.<role>.layers.

- **Category:** code
- **Default severity:** error
- **Fixable:** no

## Why

Roles give concepts a canonical home. A port defined next to its adapter, or an adapter in the application layer, drags infrastructure concerns inward and makes the concept hard to find.

## Bad

```python
# voice/infra/sql.py
class VoiceSessionRepository(Protocol):
    def save(self, session: VoiceSession) -> None: ...
```

## Good

```python
# voice/application/ports.py
class VoiceSessionRepository(Protocol):
    def save(self, session: VoiceSession) -> None: ...
```

## How to fix

Move the class into one of the role's layers; `smelt where <role>` prints the path.

## Config

- `roles.<role>.layers`
- `roles.<role>.detect`

Explain it in the terminal with `smelt explain SMT204`.

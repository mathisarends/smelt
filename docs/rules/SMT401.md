# SMT401 test-location

A test file does not live where tests.layout expects it.

- **Category:** tests
- **Default severity:** error

## Why

A predictable test location lets readers find the tests of a feature and keeps feature-scoped test runs (`pytest tests/voice`) complete.

## Bad

```python
tests/test_voice_sessions.py      # layout: feature
```

## Good

```python
tests/voice/test_sessions.py
```

## How to fix

Move the file to the expected path.

## Config

- `tests.layout`
- `tests.pattern`
- `project.test_roots`

Explain it in the terminal with `smelt explain SMT401`.

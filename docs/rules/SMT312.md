# SMT312 no-private-modules

A module or package has an underscore prefix forbidden by its naming policy.

- **Category:** structure
- **Default severity:** error

## Why

Some projects use descriptive module names and keep private helpers inside them. This opt-in naming convention rejects _service.py and _internal/ even when they export public symbols. __init__.py and __main__.py retain their Python-defined roles. Function, method, class and attribute names are outside this rule. Architecture API contracts apply independently of the spelling of a module name.

## Bad

```text
app/_service.py
app/_internal/store.py
```

## Good

```text
app/service.py
app/storage/store.py

# Inside service.py:
def run(): ...
def _prepare(): ...
```

## How to fix

Choose a descriptive module or package name without a leading underscore, then update imports and deliberate facade exports. A more specific package can explicitly allow the convention. No files or symbols are renamed automatically.

## Config

- `structure.contracts`

Explain it in the terminal with `smelt explain SMT312`.

# SMT201 concrete-construction

An adapter is instantiated outside its own layer or the composition root.

- **Category:** code
- **Default severity:** error
- **Fixable:** no

## Why

Code that constructs its collaborators decides which implementation runs. That choice belongs in the composition root, so the rest of the code can depend on ports and stay testable with fakes.

## Bad

```python
# voice/application/session.py
class StartSession:
    def __init__(self) -> None:
        self.sessions = SqlVoiceSessionRepository()
```

## Good

```python
# voice/application/session.py
class StartSession:
    def __init__(self, sessions: VoiceSessionRepository) -> None:
        self.sessions = sessions
```

## How to fix

Depend on the port and wire the implementation in the composition root.

## Config

- `roles.<role>.detect.implements`
- `architecture.composition_root`

Explain it in the terminal with `smelt explain SMT201`.

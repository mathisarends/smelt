# SMT305 unclassified-module

A module maps to no feature, layer, shared set or composition root.

- **Category:** structure
- **Default severity:** warning

## Why

Unclassified modules are exempt from layer and feature boundary checks: a domain module may import them. Composition-root/wiring restrictions and configured cycle checks still apply. Central code such as a database or storage package belongs to a layer via architecture.modules.

## Bad

```python
gateway/
  platform/db.py    # neither shared, a layer nor a feature
```

## Good

```python
# smelt.yaml
architecture:
  modules:
    gateway.platform: infrastructure
```

## How to fix

Give the package a layer under architecture.modules, list it in architecture.shared or composition_root, or move it into a feature.

## Config

- `architecture.modules`
- `architecture.shared`
- `architecture.composition_root`

Explain it in the terminal with `smelt explain SMT305`.

# SMT305 unclassified-module

A module maps to no feature, layer, shared set or composition root.

- **Category:** structure
- **Default severity:** hint

## Why

Unclassified modules are exempt from most rules. A few are normal (entry points, settings); many mean the config no longer describes the code.

## Bad

```python
gateway/
  misc.py      # neither shared nor a feature
```

## Good

```python
gateway/
  shared/misc.py
```

## How to fix

Move the module into a feature or shared, or list it in architecture.shared.

## Config

- `architecture.shared`
- `architecture.composition_root`

Explain it in the terminal with `smelt explain SMT305`.

# SMT107 private-module-import

Code outside a contracted package imports a private implementation module.

- **Category:** dependencies
- **Default severity:** error

## Why

Explicit entry points keep callers coupled to a package's supported interface. Internal imports and intentional symbol re-exports through public facades remain valid. Wiring and composition roots still obey these contracts. Layer and feature policies apply independently.

## Bad

```python
# app/client.py
from app.orders.storage import OrderStore
```

## Good

```python
# app/client.py
from app.orders.api import place_order
```

## How to fix

Import through one of the contract's public entry points. Expose a deliberate API there if needed, or explicitly revise the contract. Public entries are exact module patterns; add .** only when the whole subtree is intentionally public.

## Config

- `structure.contracts`
- `architecture.imports.type_checking`

# SMT203 forbidden-base-class

A class in a layer inherits from one of the layer's forbid_bases.

- **Category:** code
- **Default severity:** error
- **Fixable:** no

## Why

Allowing an import is not the same as allowing a framework to shape your model. A domain entity that is a pydantic model or an ORM mapping carries validation and persistence concerns wherever it goes.

## Bad

```python
# voice/domain/session.py
class VoiceSession(BaseModel): ...
```

## Good

```python
# voice/domain/session.py
@dataclass
class VoiceSession: ...
```

## How to fix

Keep the class plain and map it to framework models at the boundary (presentation or infrastructure).

## Config

- `architecture.layers.<layer>.forbid_bases`

Explain it in the terminal with `smelt explain SMT203`.

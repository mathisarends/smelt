# SMT105 shared-imports-feature

A `shared` module or a central module (`architecture.modules`) imports a feature module.

- **Category:** dependencies
- **Default severity:** error

## Why

Shared code and central layers such as a platform package are importable by every feature. If they depend on a feature, every feature transitively depends on that feature and the slices collapse.

## Bad

```python
# gateway/shared/money.py
from gateway.features.billing.domain import Currency
```

## Good

```python
# gateway/shared/money.py
class Currency: ...
```

## How to fix

Move the needed concept into shared, or move the shared code into the feature.

## Config

- `architecture.shared`
- `architecture.modules`

Explain it in the terminal with `smelt explain SMT105`.

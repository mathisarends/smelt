# SMT105 shared-imports-feature

A `shared` module imports a feature module.

- **Category:** dependencies
- **Default severity:** error

## Why

Shared code is importable by every feature. If it depends on a feature, every feature transitively depends on that feature and the slices collapse.

## Bad

```python
# gateway/shared/money.py
from gateway.features.billing.domain import Currency
```

## Good

```python
# gateway/shared/money.py
class Currency: ...
```

## How to fix

Move the needed concept into shared, or move the shared code into the feature.

- `architecture.shared`

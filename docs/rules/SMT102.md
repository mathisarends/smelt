# SMT102 cross-feature-import

A feature imports another feature outside the allowed layer pairs.

- **Category:** dependencies
- **Default severity:** error

## Why

Features are independent slices. Direct imports between them couple release cycles and make it impossible to reason about one feature in isolation.

## Bad

```python
# billing/infra/charges.py
from gateway.features.voice.infra.sql import CallLog
```

## Good

```python
# billing/application/charges.py
from gateway.features.voice.application.api import CallSummaryQuery
```

## How to fix

Go through an allowed layer pair (for example application -> application), move the shared concept into a `shared` package, or merge the features.

## Config

- `architecture.cross_feature.default`
- `architecture.cross_feature.allow`

Explain it in the terminal with `smelt explain SMT102`.

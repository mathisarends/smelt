# IDM009 idioms/redundant-getattr

A literal getattr or hasattr reads an attribute that the receiver's declared project type always has.

- **Category:** idioms
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** hint
- **Automatic fix:** none; repair by hand
- **Guide:** Read attributes the declared type guarantees directly instead of through getattr or hasattr

## Why

getattr(obj, 'name', default) and hasattr(obj, 'name') suggest that the attribute can be missing and hide the access from the type checker. When every project class of the receiver's declared type declares it, the plain attribute read behaves the same and stays checked. The opt-in hint checks production modules. Receiver types come from parameter annotations, unannotated method receivers, locals assigned once from an annotation, a project class constructor or an annotated project function, loop targets over annotated collections, annotated instance attributes and properties, and type aliases of project class unions. An attribute counts as declared by a class-body assignment, method, property or nested class, an annotation in a dataclass-like class with a decorator or base, an unconditional receiver assignment at the top of __init__, or a project base that declares it. Receivers typed Any, object, a type parameter, an outside class, an Optional or a union member without the attribute stay quiet, as do dunder names, TypedDicts, classes with __getattr__, __getattribute__ or __slots__ in their project chain, and receivers inside construction methods such as __init__. Attributes added by setattr, monkeypatching or metaclasses are outside its inference.

## Bad

```python
def last_activity(entries: tuple[UserMessage | ToolCall, ...]) -> datetime:
    latest = datetime.min
    for entry in entries:
        created_at = getattr(entry, "created_at", None)
        if isinstance(created_at, datetime) and created_at > latest:
            latest = created_at
    return latest
```

## Good

```python
def last_activity(entries: tuple[UserMessage | ToolCall, ...]) -> datetime:
    latest = datetime.min
    for entry in entries:
        if entry.created_at > latest:
            latest = entry.created_at
    return latest
```

## How to fix

Read the attribute directly, and replace hasattr checks by the branch they guarded. Then review checks on the value, such as an isinstance test or a None default, that the declared type already settles. Keep the reflection when the attribute is meant to be optional, and declare it optional in the class instead. No automatic rewrite is performed.

# LAY013 layout/workspace-layout-convention

A top-level package deviates from the uv workspace's folder layout.

- **Category:** layout
- **Activation:** explicit — Enable by rule setting or --select; requires that project.workspace is uv and project.workspace_layout selects flat or src.
- **Severity when active:** error
- **Automatic fix:** none; repair by hand
- **Guide:** Use the workspace's canonical layout for top-level packages

## Why

One workspace-wide layout makes package locations predictable. Choose flat for member/member or src for member/src/member. Smelt checks the top-level packages selected by its source roots and package discovery, including selected namespace packages. The last directory of the member path gives the expected package name. For the workspace root's own project, use its project.name from pyproject.toml. Names are lowercased and runs of hyphens, dots and underscores become one underscore.

## Bad

```text
# With project.workspace_layout: src
services/backend/backend/__init__.py
```

## Good

```text
# With project.workspace_layout: src
services/backend/src/backend/__init__.py
```

## How to fix

Move the package to the expected directory or align the member directory name with its intended package. Update build configuration, Smelt source roots and package selection, workspace globs, and any imports affected by a package rename. Review existing destination files before moving code.

## Config

- `project.workspace`
- `project.workspace_layout`
- `project.source_roots`
- `project.root_packages`

Explain it in the terminal with `smelt explain LAY013`.

# SMT309 forbidden-module-docstring

A module docstring is forbidden by the package's explicit convention.

- **Category:** structure
- **Activation:** policy — A package contract forbids module docstrings.
- **Severity when active:** error

## Why

Some projects keep module descriptions in their architecture documentation. This opt-in convention checks the module's initial docstring, including empty strings and package initializers, not function or class documentation or ordinary strings. Choose module_docstrings: forbid for this rule or require for the opposite convention (SMT325); allow explicitly exempts a nested package.

## Bad

```python
"""Redundant module introduction."""
VALUE = 1
```

## Good

```python
VALUE = 1

def calculate():
    """Explain the calculation contract."""
```

## How to fix

Remove or move the module introduction according to the package's policy. Mark an intentional file exception with # smelt: ignore-file[SMT309] -- reason. No documentation is deleted automatically.

## Config

- `structure.contracts`

Explain it in the terminal with `smelt explain SMT309`.

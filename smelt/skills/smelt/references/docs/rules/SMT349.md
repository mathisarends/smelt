# SMT349 stateful-dataclass

A dataclass mutates its own fields after construction.

- **Category:** structure
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** hint

## Why

A dataclass reads as a value: its generated __init__ is the constructor and its fields are what callers may rely on. When methods keep writing to self, the class is really a mutable accumulator or state machine with a value-like surface: callers can construct it in a half-built state, observe fields that are only scratch space for private helpers, and share instances whose contents change underneath them. Building the values first and passing them to a frozen dataclass, or keeping the accumulation in a plain class with private attributes, makes the lifecycle explicit. This opt-in review reports a @dataclass that is not frozen=True when a method other than __post_init__ assigns, deletes or augments an attribute of self, assigns or deletes an item of a field, calls a mutating container method such as append, add, update, pop or discard on a field declared as a mutable container, or calls setattr on self. Mutations inside nested functions of a method count. Calls that mutate through other objects, classes that are not dataclasses and tests are not reported. Intentional mutable records can keep a reasoned suppression.

## Bad

```python
@dataclass
class InterruptedActivity:
    turn: str | None = None
    started: set[str] = field(default_factory=set)

    @classmethod
    def scan(cls, events: Iterable[Event]) -> Self:
        activity = cls()
        for event in events:
            activity._observe(event)
        return activity

    def _observe(self, event: Event) -> None:
        if isinstance(event, TurnStarted):
            self.turn = event.turn_id
        elif isinstance(event, ToolStarted):
            self.started.add(event.call_id)
```

## Good

```python
@dataclass(frozen=True)
class InterruptedActivity:
    turn: str | None
    started: frozenset[str]

    @classmethod
    def scan(cls, events: Iterable[Event]) -> Self:
        turn = None
        started: set[str] = set()
        for event in events:
            if isinstance(event, TurnStarted):
                turn = event.turn_id
            elif isinstance(event, ToolStarted):
                started.add(event.call_id)
        return cls(turn=turn, started=frozenset(started))
```

## How to fix

Compute the field values first and pass them to the constructor of a frozen dataclass, using immutable field types such as tuple, frozenset or Mapping; derive further values with properties or dataclasses.replace. When the object genuinely accumulates state, make it a plain class whose scratch attributes are private, or move the accumulation into a separate builder. No automatic rewrite is performed. Enable rules: {stateful-dataclass: hint}, or select SMT349. Package overrides and reasoned inline suppressions are supported.

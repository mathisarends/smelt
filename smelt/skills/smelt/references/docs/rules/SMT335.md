# SMT335 internal-public-attribute

A public instance or class data attribute has no observed access outside its class.

- **Category:** structure
- **Activation:** explicit — Enable by rule setting or --select.
- **Severity when active:** warning

## Why

Implementation state should not advertise a public interface solely because it lacks a leading underscore. This opt-in review covers direct instance assignments in ordinary methods and simple class data declarations on unambiguous top-level classes, including unused attributes. Any same-named access outside the owning class conservatively preserves visibility, including unresolved receivers, writes, deletions and literal reflection. Test accesses count even when test-quality rules exclude the file; test-only reads remain the responsibility of SMT430, so these rules do not overlap. Private names, methods/properties, possible descriptors, decorated/inherited/subclassed classes, slots and custom attribute hooks are excluded. This also preserves dataclass, attrs, Pydantic, NamedTuple and TypedDict data contracts. Classes explicitly exported through __all__ or public package-facade bindings retain their public attributes, including aliased re-export chains. Inheritance is excluded as a whole rather than attempting to prove which fields a framework or base class owns. Excluded files (including maintainer scripts), unselected packages, external consumers and arbitrary dynamic access are unassessed, not proven absent; usage_scope records the configured analysis boundary. This review does not prove that renaming is safe.

## Bad

```python
class Readiness:
    def __init__(self, initial):
        self.initial = initial
    def select(self):
        return self.initial
```

## Good

```python
class Readiness:
    def __init__(self, initial):
        self._initial = initial
    def select(self):
        return self._initial
```

## How to fix

Review whether the attribute belongs to the supported API. For internal state, add a leading underscore and update internal reads and writes, checking name collisions and dynamic consumers. Preserve deliberate public contracts with `# smelt: ignore[SMT335] -- <specific API reason>` on the reported assignment or declaration, or a package rule override. Suggested names avoid observed collisions; no automatic rename is performed. Enable rules: {internal-public-attribute: warning} or select --select SMT335.
